# aidin_hand2_msgs

Command and state message definitions and a service definition for the AIDIN Hand Gen2.
The [package guide (Korean)](README.ko.md) covers message and service fields, units,
and joint and actuator array order. Definitions are in [msg/](msg) and [srv/](srv).

Topic publishing, service calls and monitoring are covered in the
[Control guide (Korean)](../docs/ko/05_control_guide.md).
